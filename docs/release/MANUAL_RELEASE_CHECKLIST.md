# Workbench release checklist

Complete this checklist on the CachyOS release machine. Save a completed copy
outside the repository and pass its path with `--checklist` to
`scripts/release.sh`; the script preserves that copy with its evidence.

- [ ] Verified light theme at desktop placement.
- [ ] Verified dark theme at desktop placement.
- [ ] Verified light theme in compact/panel placement.
- [ ] Verified dark theme in compact/panel placement.
- [ ] Completed the critical task, timer, report, and Plane workflows using keyboard-only navigation.
- [ ] Confirmed category colors remain readable and status is not color-only.
- [ ] Verified a clean archive install starts with no unexpected task data.
- [ ] Verified an upgrade preserves tasks, active-timer recovery, settings, and the legacy plugin/database identifiers.
- [ ] Reviewed Appium screenshots and logs, including compact and 200% scaling variants.
