# Primary references

This reference list was reviewed on 2026-09-14. Prefer these primary KDE, Qt, and Arch Linux sources over older blog posts or Plasma 5 examples.

## KDE Plasma widget development

### [Plasma Widget tutorial](https://develop.kde.org/docs/plasma/widget/)

KDE’s documentation index for Plasma widgets. It links to package setup, QML, properties, configuration, testing, examples, translation, and native extensions.

### [Plasma widget setup](https://develop.kde.org/docs/plasma/widget/setup/)

Defines the package layout, `metadata.json`, `contents/ui/main.qml`, representations, and the Plasma 6 `PlasmoidItem` root requirement.

### [Porting Plasmoids to KF6](https://develop.kde.org/docs/plasma/widget/porting_kf6/)

Explains Plasma 6 API separation and metadata changes. Use this guide to identify Plasma 5 examples that require conversion.

### [Widget properties](https://develop.kde.org/docs/plasma/widget/properties/)

Documents access to applet properties through the attached `Plasmoid` object and lowercase `plasmoid` context property.

### [Widget configuration](https://develop.kde.org/docs/plasma/widget/configuration/)

Documents `contents/config/main.xml`, configuration pages, supported KConfig types, and `plasmoid.configuration`.

### [Widget testing](https://develop.kde.org/docs/plasma/widget/testing/)

Documents `plasmawindowed`, `plasmoidviewer`, form-factor simulation, HiDPI testing, and QML debug logging.

### [Widget translations and i18n](https://develop.kde.org/docs/plasma/widget/translations-i18n/)

Documents KDE translation extraction and `i18n()` usage in plasmoids.

### [C++ API for Plasma widgets](https://develop.kde.org/docs/plasma/widget/c-api/)

Explains private C++ QML extensions for advanced models and file access. Some samples still use Qt 5 and KF5 names, so convert samples to the installed Qt 6 and KF6 APIs.

API index for Kirigami layouts, cards, forms, theme values, icons, and messages.

### [KDE Human Interface Guidelines](https://develop.kde.org/hig/)

## Charts

### [KQuickCharts overview](https://api.kde.org/kquickcharts-index.html)

Explains KDE’s high-performance QML charts, data sources, axes, and legends.

### [`BarChart` QML type](https://api.kde.org/qml-org-kde-quickcharts-barchart.html)

Documents the bar chart recommended for weekly and monthly work-time reports.

## Qt Quick models and interaction

### [`ListView` QML type](https://doc.qt.io/qt-6/qml-qtquick-listview.html)

Documents list delegates, sections, transitions, reuse, model roles, and the requirement to keep state outside delegates.

### [Dynamic view ordering tutorial](https://doc.qt.io/qt-6/qtquick-tutorials-dynamicview-dynamicview3-example.html)

Shows drag reordering with `Drag`, `DropArea`, and `DelegateModel`. The example changes visual order only. Workbench must also persist source-model order.

### [`Drag` attached property](https://doc.qt.io/qt-6/qml-qtquick-drag.html)

Documents drag events generated by a QML item.

### [`DropArea` QML type](https://doc.qt.io/qt-6/qml-qtquick-droparea.html)

Documents the receiving area for drag events.

### [`DragHandler` QML type](https://doc.qt.io/qt-6/qml-qtquick-draghandler.html)

Documents pointer-driven drag handling.

### [`QSortFilterProxyModel`](https://doc.qt.io/qt-6/qsortfilterproxymodel.html)

Stable C++ API for sorting and filtering a source item model.

### [QML `SortFilterProxyModel`](https://doc.qt.io/qt-6/qml-qtqml-models-sortfilterproxymodel.html)

QML sort-and-filter API introduced in Qt 6.10. Qt marks this API as preliminary. Version 1 should not depend on it.

## Local storage and time

### [Qt Quick Local Storage](https://doc.qt.io/qt-6/qtquick-localstorage-qmlmodule.html)

Documents synchronous SQLite access from QML JavaScript, database transactions, version changes, and parameter binding.

### [`Timer` QML type](https://doc.qt.io/qt-6/qml-qtqml-timer.html)

Documents the visual refresh timer. Persisted timestamps must remain the source of truth for elapsed time.

### [`QDateTime`](https://doc.qt.io/qt-6/qdatetime.html)

Native date-time API for a future C++ report engine.

### [`QTimeZone`](https://doc.qt.io/qt-6/qtimezone.html)

Native IANA timezone and daylight-saving API for a future C++ report engine.

### [`QSqlDatabase`](https://doc.qt.io/qt-6/qsqldatabase.html)

Native database connection API for a future Qt/C++ repository.

### [`QStandardPaths`](https://doc.qt.io/qt-6/qstandardpaths.html)

Defines platform-standard storage paths. On Linux, `GenericDataLocation` maps to `~/.local/share` as the writable user location.

## CachyOS and Arch package references

CachyOS is Arch-based. Verify package versions on the installed system because CachyOS repositories and update timing can differ from Arch repositories.

### [Arch `plasma-sdk`](https://archlinux.org/packages/extra/x86_64/plasma-sdk/)

Provides applications useful for Plasma development and depends on the primary Plasma and Qt runtime components.

### [Arch `libplasma`](https://archlinux.org/packages/extra/x86_64/libplasma/)

Provides Plasma libraries, headers, CMake metadata, and QML modules.

### [Arch `kquickcharts`](https://archlinux.org/packages/extra/x86_64/kquickcharts/)

Provides the `org.kde.quickcharts` QML module.

### [Arch `kpackagetool6` manual](https://man.archlinux.org/man/kpackagetool6.1.en)

Documents Plasma package installation, upgrade, listing, and removal commands.

## Compatibility policy

Use these rules while implementing the product:

1. Prefer public KDE and Qt modules.
2. Avoid `org.kde.plasma.private.*` imports owned by other widgets.
3. Treat Plasma 5 examples as migration references, not copy-ready Plasma 6 code.
4. Set the minimum Plasma and Qt versions from used APIs.
5. Avoid preliminary APIs when a stable alternative exists.
6. Test every release against the current CachyOS packages and the declared minimum versions.
7. Record upstream behavior changes in the project changelog before raising the minimum version.
