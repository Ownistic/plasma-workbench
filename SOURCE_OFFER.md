# Corresponding Source

This distribution includes the complete corresponding source used to build its
native time module in `source/`. Build it with the included `CMakeLists.txt`
and the commands in `source/README.md`.

The source directory excludes only Git metadata, generated build output,
session tooling, and generated packaged plugin binaries. It includes the QML,
C++, tests, CMake build scripts, licensing files, and packaging scripts needed
to reproduce the distributed native module.
